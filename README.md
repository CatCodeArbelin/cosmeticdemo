# cosmeticdemo
DEMO
Сделай DEMO-прототип AI-помощника для менеджеров косметического магазина.

Цель:
Показать клиенту механику будущей системы:
FakeMAX / Telegram → Telegram-хаб менеджера → AI-подсказки → менеджер выбирает ответ → система “отправляет” ответ обратно клиенту.

Это НЕ production.
MAX в демо имитируется через команду /demo_max и HTTP endpoint.
Реальную интеграцию MAX пока НЕ делать.

Стек:
- Python 3.11+
- aiogram 3
- FastAPI
- OpenAI API
- SQLite
- Docker
- docker-compose
- python-dotenv

Функционал Telegram-бота:

1. /start
Показывает приветствие:

“AI-помощник менеджера запущен.

Команды:
 /demo_max — тестовое сообщение из MAX
 /demo_tg — тестовое сообщение из Telegram
 /help — инструкция”

2. /demo_max
Создает тестовый входящий диалог:

source = "MAX"
client_name = "Анна"
client_message = "Здравствуйте! Нужен уход для сухой кожи 35+, что можете посоветовать?"

После этого бот должен:
- сохранить сообщение в SQLite;
- вызвать OpenAI;
- получить 2 варианта ответа;
- отправить менеджеру карточку в Telegram.

Карточка должна выглядеть примерно так:

🟣 Новое сообщение из MAX

Клиент: Анна

Сообщение:
Здравствуйте! Нужен уход для сухой кожи 35+, что можете посоветовать?

AI предлагает:

Вариант 1:
...

Вариант 2:
...

Кнопки:
[✅ Отправить 1]
[✅ Отправить 2]
[🔄 Сгенерировать заново]
[✍️ Ответить вручную]

3. /demo_tg
Создает тестовое входящее сообщение:

source = "Telegram"
client_name = "Мария"
client_message = "Добрый день! Есть ли у вас сыворотка для чувствительной кожи?"

Логика такая же, как /demo_max.

4. Кнопка “Отправить 1” / “Отправить 2”
В демо реальная отправка клиенту не нужна.
Бот должен написать:

“✅ Ответ отправлен клиенту в MAX:
<текст ответа>”

или:

“✅ Ответ отправлен клиенту в Telegram:
<текст ответа>”

Также обновить статус в SQLite: sent.

5. Кнопка “Сгенерировать заново”
Повторно вызвать OpenAI для этого же сообщения.
Обновить AI-варианты.
Отправить новую карточку менеджеру.

6. Кнопка “Ответить вручную”
Бот пишет:

“✍️ Напишите ручной ответ следующим сообщением.”

Следующее сообщение менеджера считается ручным ответом.
После получения ручного ответа бот пишет:

“✅ Ручной ответ отправлен клиенту в MAX/Telegram:
<текст>”

Статус в SQLite: manual_sent.

7. FastAPI endpoint

POST /mock/incoming

JSON body:

{
  "source": "MAX",
  "client_name": "Анна",
  "message": "Здравствуйте, нужен уход для сухой кожи"
}

Endpoint должен:
- сохранить сообщение;
- вызвать OpenAI;
- отправить карточку менеджеру в Telegram;
- вернуть JSON:

{
  "ok": true,
  "message_id": 123
}

Это нужно для демонстрации, как в будущем MAX будет отправлять входящие сообщения через webhook.

8. База знаний

Создать файл app/knowledge_base.md.

Заполнить тестовыми данными:

# База знаний магазина

## Общие правила
- Магазин продает профессиональную косметику.
- Рекомендации должны быть общими, не медицинскими.
- Нельзя обещать лечение акне, дерматита, розацеа и других заболеваний.
- Нельзя гарантировать результат.
- При подборе ухода нужно уточнять тип кожи, возраст, чувствительность, бюджет и текущий уход.
- Общаться на “вы”.
- Стиль: дружелюбно, профессионально, коротко.

## Сухая кожа
Для сухой кожи обычно рекомендуют мягкое очищение, увлажняющую сыворотку, крем для восстановления защитного барьера. Важно избегать агрессивного очищения.

## Чувствительная кожа
Для чувствительной кожи лучше предлагать мягкие средства без агрессивных активов. Нужно уточнить, есть ли реакция на кислоты, ретинол, витамин C и отдушки.

## Доставка
Доставка обсуждается индивидуально. Менеджер может уточнить город клиента.

## Оплата
Оплата обсуждается с менеджером после подбора товаров.

9. OpenAI prompt

Сделать system prompt:

Ты AI-помощник менеджера магазина профессиональной косметики.
Ты НЕ отвечаешь клиенту напрямую.
Ты предлагаешь менеджеру 2 коротких варианта ответа.
Ответы должны быть на русском языке.
Обращение на “вы”.
Стиль: профессиональный, дружелюбный, без давления.
Не давай медицинских обещаний.
Не используй слова “лечит”, “избавит от заболевания”, “гарантирует результат”.
Если клиент спрашивает про заболевания кожи, посоветуй обратиться к врачу/дерматологу и предложи только общий уход.
Всегда старайся задать 1–2 уточняющих вопроса, если данных недостаточно.

User prompt должен включать:
- источник сообщения;
- имя клиента;
- сообщение клиента;
- knowledge_base.md;
- просьбу вернуть строго JSON:

{
  "variant_1": "...",
  "variant_2": "..."
}

Нужно обработать ошибку, если OpenAI вернул невалидный JSON:
- использовать fallback parsing;
- если не получилось, вернуть 2 стандартных варианта.
